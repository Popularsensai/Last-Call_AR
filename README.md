# Last-Call_AR

An AR game for bartending, use your hand gestures to pour drinks in the tumbler, shake or stir according to the recipe and pour the drink out to the customers in the margarita glass. Yellow hands indicate you are not grabbing anything, pink means you are pinching/ holding. One hand mode turned on by default. Deal with creeps or hasslers (in purple) by throwing a towel or calling the bouncer.
